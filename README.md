# 📒 Contact Book using Python

A simple and beginner-friendly Contact Book application built using Python. This project allows users to manage their contacts through a menu-driven interface and stores contact details in a JSON file.

## ✨ Features

- ➕ Add new contacts
- 📋 View all saved contacts
- 🔍 Search contacts by name
- ✏️ Update existing contact details
- 🗑️ Delete contacts with confirmation
- 💾 Store contacts permanently using JSON file handling
- ⚠️ Handle invalid menu choices and missing contacts

## 🛠️ Technologies Used

- **Python** – Core programming language
- **JSON** – To store contact information
- **OS Module** – To check whether the contacts file exists
- **VS Code** – Development environment

## 📂 Project Structure

```text
contact-book/
│
├── main.py
├── contacts.json
└── README.md
```

**Note:** `contacts.json` is created automatically when you add your first contact.

## 🚀 How to Run the Project

### Step 1: Install Python

Download Python from [python.org](https://www.python.org/downloads/) if it is not already installed.

### Step 2: Download the Project

Download this repository as a ZIP file and extract it, or clone it using Git.

### Step 3: Open the Project

Open the project folder in Visual Studio Code.

### Step 4: Run the Application

Open the terminal and execute:

```bash
python main.py
```

On Windows, you can also use:

```bash
py main.py
```

## 📱 How to Use

After running the program, select an option from the menu:

1. Add Contact
2. View All Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit

Follow the instructions displayed in the terminal to manage your contacts.
